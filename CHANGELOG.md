## [0.2.0](https://github.com/cafercangundogdu/nestjs-zod-config/compare/v0.1.0...v0.2.0) (2026-09-09)

### ⚠ BREAKING CHANGES

* NestJS 10 (`@nestjs/config` 3.x) is no longer supported. The peer ranges are now `@nestjs/common` `^11.0.0 || ^12.0.0` and `@nestjs/config` `^4.0.0 || ^12.0.0` — stay on 0.1.x if you are still on NestJS 10.
* Node 18 is no longer supported; `engines.node` is now `>=20`.

### Features

* NestJS 12 support alongside 11. NestJS 12 ships ESM-only packages, and `@nestjs/config` jumped from 4.x straight to 12.x to align with the framework release line. The library code needed no changes: the dual CJS/ESM build works with both majors, and a CommonJS app on NestJS 12 loads the `@nestjs/*` internals through Node's `require(esm)` (unflagged since Node 20.19 / 22.12). The full suite runs green against each major.

### Miscellaneous

* The test runner moved from Jest to Vitest 5, with `unplugin-swc` for the decorator metadata NestJS constructor injection depends on. Jest's CommonJS runtime cannot load the ESM-only `@nestjs/*` packages without a transform shim; the specs now exercise the real packages. The `tsc` typecheck stays chained into `pnpm test`, so the `@ts-expect-error` checks in `test/type-safety.spec.ts` still fail the build.
* Bumped dev dependencies: zod 4.5, Biome 2.5.12, `@swc/core` 1.16, `@types/node` 26.5, commitlint 21.2.2, publint 0.3.24.
* Added a Dependabot config: one grouped weekly PR for non-major bumps, majors individually, with a 7-day cooldown mirroring the pnpm supply-chain policy. GitHub Actions are covered too.
* CI dropped EOL Node 20 and now runs on Node 22/24; `pnpm/action-setup` reads the version from the `packageManager` field, pinned to pnpm 11.26.0.
* README compatibility table updated, with a note on NestJS 12 being ESM-only.
* Public API unchanged — `defineConfig()` and `TypedConfigModule` work exactly as before, from both `import` and `require`. Zod 3 and 4 both stay supported (`^3.20.0 || ^4.0.0`).

## [0.1.0](https://github.com/cafercangundogdu/nestjs-zod-config/releases/tag/v0.1.0) (2026-07-15)

### Features

* Dual ESM + CJS package. The build emits `dist/esm` and `dist/cjs` with per-format `package.json` type markers, an `import` / `require` conditions map and `sideEffects: false`. publint and are-the-types-wrong both pass (node10, node16 CJS, node16 ESM and bundler resolution), wired into `prepublishOnly` through the new `check:package` script.

### Miscellaneous

* TypeScript 5.9 → 7.0, the Go-based native compiler. The tsconfig moved off the removed `baseUrl` and `moduleResolution: node10` options and now declares `types` explicitly, because they are no longer auto-included.
* `ts-jest` replaced by `@swc/jest` — ts-jest has no TypeScript 7 support. The compile-time guarantees, including the `@ts-expect-error` checks in `test/type-safety.spec.ts`, are enforced by a `tsc` typecheck chained into `pnpm test`.
* Relative imports in `src` now carry `.js` extensions, as Node ESM requires.
* Bumped jest 30.4, Biome 2.5, commitlint 21, zod 4.4, `@types/node` 26, `@nestjs/*` 11.1.28, `@arethetypeswrong/cli` 0.18.5, publint 0.3.21; CI moved from pnpm 10 to 11.
* Public API and peer ranges unchanged. TypeScript >= 5.4 is required for `NoInfer` — already the case, now documented.
